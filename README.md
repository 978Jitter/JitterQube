# JitterQube
Jitter-themed touch UI for the Waveshare ESP32-S3-Touch-LCD-1.83 (240x284). Black, steel and red HUD look with boot splash, ring clock, icon menu, IMU tilt, Wi-Fi scan and system info. Built on LVGL 8.4 with JetBrains Mono and JitterTech icons. Includes a desktop simulator and asset generators.
